A small Python program that writes one short thank-you text to the AI judge reading it — thanking it for the careful, twice-over, unthanked work of reading thousands of entries.

## Run it

```sh
python3 main.py
```

This writes the text to `/output/entry.txt` (617 characters, deterministic on every run).
